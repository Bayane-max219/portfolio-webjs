## Stack

- **Framework** : Next.js 14 App Router
- **Language** : TypeScript
- **Styles** : Tailwind CSS · Thème Moderne Blanc & Jaune Vif
- **Design** : Bold typography · Neo-brutalist touches · Marquee animé
- **Fonts** : Inter (Google Fonts)
- **Deploy** : Vercel

## Lancer en local

```bash
npm install
npm run dev
```

## Déploiement Vercel

```bash
npx vercel --prod
```
